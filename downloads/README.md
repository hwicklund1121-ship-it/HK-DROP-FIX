# Experimental downloads

**Do not use `HK_LUGU_NoMotorbike-TEST.zip` (v1).** A reported DayZ 1.30 crash
showed that its main player AGR failed to open. It remains in history for
comparison, not as a recommended download.

`HK_LUGU_NoMotorbike-TEST-v2.zip` preserves the original compressed resource
entry format and metadata. This is an unverified packaging correction, not a
confirmed fix for the crash or hands-up pose. Read its included README, keep
your original Luigi PBO for rollback, and stop using V2 if graph loading fails.

Files with `SOURCE-ONLY` in their names are authoring inputs, not installable
mods. `HK_CrouchHandsGuard-experimental.zip` did not resolve the reported pose.
