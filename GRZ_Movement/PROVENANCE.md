# GRZ release contents and rights notes

The standalone GRZ package contains newly written movement-parameter and camera-policy scripts, configuration, and these documents. It does not contain LUGU, StormZz, LWP or Ronjam scripts, PBOs, animation graphs, animation clips, branding, or obfuscated resources. It depends on an installed, licensed copy of DayZ and uses DayZ scripting interfaces.

Development used the supplied movement settings as a behavior reference, inspected supplied mods, and consulted DayZ script interfaces. This is not a claim of an independent clean-room process. Similar behavior or numerical tuning alone does not establish infringement, but this document is not legal clearance or a guarantee against claims.

The LUGU addon remains a separate optional installation. Permission to use it does not necessarily include permission to redistribute it. Obtain permission before bundling any third-party addon or using another creator's artwork or branding. No trademark search for GRZ Movement has been performed. DayZ and third-party platform license terms still apply.

Distribute the standalone GRZ ZIP, not an archive of the historical HK-DROP-FIX repository: that repository contains third-party inputs and earlier experimental packages which are outside this GRZ release.
